# LapZero

This will be a genetic algorithm racing visualizer. The user will be able to
draw a track by hand, then watch a population of simple neural net
"racers" evolve, generation by generation, until they can drive it.


## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
